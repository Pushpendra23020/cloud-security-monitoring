# Security Policy

## Supported version

Security fixes are applied to the latest commit on the `main` branch. This
project is an actively developed MVP and does not currently maintain older
release branches.

## Reporting a vulnerability

Please do not disclose vulnerabilities in a public issue, discussion, pull
request, screenshot or demonstration recording.

Use GitHub's **Report a vulnerability** option under the repository's
**Security** tab to submit a private vulnerability report. Include:

- the affected component and version or commit;
- clear reproduction steps or a minimal proof of concept;
- the potential impact and required attacker access; and
- suggested remediation, if known.

Do not include real AWS credentials, customer data, access tokens or production
account identifiers. Use synthetic test data only. Do not perform denial-of-
service testing, destructive testing or access data belonging to another user.

The maintainer will acknowledge a complete report as soon as practical,
validate the issue, coordinate a remediation and publish an advisory when a fix
is available. No bounty or response-time guarantee is currently offered.
